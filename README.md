## ⚡ Core Architecture Features

* **Unified Dual-Engine Gateway:** Features a decoupled processing routing system that toggles execution contexts dynamically between **Corporate Mode** and **Grahasti Mode**.
* **Enterprise Threat & Escrow Mitigation:** Intercepts high-risk payloads containing malicious SQL injection attacks (`DROP TABLE`, `UNION SELECT`) or unmasked PII credential leaks. Automates immediate `ESCROW LOCKED` safety thresholds.
* **Household Micro-CPI Inflation Forecaster:** Parses raw daily spending streams and identifies hidden lifestyle inflation overheads—specifically calculating convenience premiums introduced by dark stores (Zepto, Blinkit).
* **90-Day Predictive Run-Rate:** Generates high-depth forward-looking burn projections and provides direct, actionable optimization strategies to secure a localized financial buffer.
* **Instant Production Mock Injectors:** Embedded with direct bulk testing scenarios (`data-injectors.js`) enabling instantaneous visual performance updates during live demonstrations.
